OpenFishing налаштовується лише змінними середовища, у розділі `environment:` вашого файлу
compose (або через `-e` у `docker run`). Стандартні значення нижче — це значення в образі
Docker. Майже кожне встановлення задає `BASE_URL` і `TZ`; решта необов'язкова.

## Адреса й час

- **`BASE_URL`** · стандартно: не задано\
  Адреса, за якою відкривають OpenFishing, з `http://` або `https://`, наприклад
  `http://192.168.1.50:3000` або `https://fishing.example.com`. Сервер бере з неї схему:
  **без неї він вважає, що працює через HTTPS, і на встановленні без TLS кожне збереження
  відхиляється** («Cross-site POST form submissions are forbidden»). Вона також формує посилання в QR-кодах і посилання для поширення, які без неї ведуть на `http://localhost:5173`.
- **`PROTOCOL_HEADER`** · стандартно: не задано\
  Лише для reverse proxy, який сам повідомляє схему, наприклад `PROTOCOL_HEADER=x-forwarded-proto`.
  Якщо задано, має пріоритет над схемою з `BASE_URL`.
- **`TZ`** · стандартно: UTC\
  Ваш часовий пояс, наприклад `Europe/Kyiv` або `America/New_York`. Без нього час уловів зсунутий.

## Зберігання

- **`DATABASE_URL`** · стандартно: `/app/data/openfishing.db`\
  Файл бази SQLite у томі `/app/data`. Не змінюйте.
- **`UPLOAD_PATH`** · стандартно: `/app/uploads`\
  Де зберігаються фото, у томі `/app/uploads`. Не змінюйте.
- **`BODY_SIZE_LIMIT`** · стандартно: `104857600` (≈ 100 МБ)\
  Найбільше завантаження в байтах. Reverse proxy перед застосунком потребує такого ж ліміту.

## Вхід

- **`ADMIN_PASSWORD`** · стандартно: не задано\
  Вмикає вхід. Це пароль облікового запису `admin` (ім'я користувача завжди `admin`), який
  зчитується під час кожного запуску. Не задано: екземпляр відкритий, без екрана входу.
- **`AUTH_PASSWORD`** · застаріла\
  Стара назва `ADMIN_PASSWORD`. Досі працює; використовуйте `ADMIN_PASSWORD`.

Див. [Багатокористувацький режим і автентифікація](/uk/docs/multi-user/authentication).

## Пошта для скидання пароля

Опція «забули пароль» з'являється, лише якщо задано принаймні `SMTP_HOST` і `SMTP_FROM`.

- **`SMTP_HOST`** · стандартно: не задано\
  Ваш поштовий сервер.
- **`SMTP_PORT`** · стандартно: `587`\
  Порт `465` означає TLS; інші порти використовують STARTTLS.
- **`SMTP_SECURE`** · стандартно: не задано\
  Задайте `true` для неявного TLS (зазвичай із портом 465).
- **`SMTP_USER`** / **`SMTP_PASS`** · стандартно: не задано\
  Облікові дані поштового сервера. Пропустіть для релеїв без входу.
- **`SMTP_FROM`** · стандартно: не задано\
  Відправник, наприклад `OpenFishing <noreply@example.com>`.

Наприклад, з поштовим акаунтом на порту 587:

```yaml title="docker-compose.yml"
    environment:
      - SMTP_HOST=smtp.example.com
      - SMTP_PORT=587
      - SMTP_USER=you@example.com
      # Пароль поштового акаунта
      - SMTP_PASS=
      - SMTP_FROM=you@example.com
```

## Мапа

- **`MAP_TILE_URL`** · стандартно: OpenStreetMap\
  Шаблон адреси плиток, щоб
  використовувати власний чи інший сервер плиток замість OpenStreetMap.\
  Наприклад: `https://tiles.example.com/{z}/{x}/{y}.png`
- **`MAP_TILE_ATTRIBUTION`** · стандартно: не задано\
  Атрибуція, що показується на мапі для `MAP_TILE_URL`. Більшість постачальників її вимагає.

## Функції ШІ

- **`CHATBOT`** · стандартно: не задано\
  Задайте `true`, щоб увімкнути чат-бот ШІ. Потрібні налаштування LiteLLM нижче. Див. [Функції ШІ](/uk/docs/ai/ai-features).
- **`LITELLM_URL`** · стандартно: не задано\
  Ваш проксі LiteLLM, наприклад `http://litellm:4000`.
- **`LITELLM_MODEL`** · стандартно: не задано\
  Модель чат-бота, що відповідає `model_name` у вашому `litellm.config.yaml`.
- **`LITELLM_VISION_MODEL`** · стандартно: не задано\
  Необов'язкова модель для розпізнавання риб і приманок на фото. Інакше використовується `LITELLM_MODEL`.

Див. [Функції ШІ](/uk/docs/ai/ai-features).

## Демо

- **`DEMO_MODE`** · стандартно: не задано\
  **Будь-яке** значення вмикає демо-режим лише для перегляду, навіть `false` чи `0`. Щоб вимкнути,
  видаліть рядок. Див. [Демо-режим](/uk/docs/demo/demo-mode).
