**Посилання для поширення** дають змогу опублікувати окрему **приманку**, **місце** чи **улов** як публічну
сторінку лише для читання — зручно, щоб похвалитися уловом або поділитися приманкою з другом, не надаючи йому
доступу до всієї вашої інстанції.

:::note
Посилання для поширення потребують входу. Коли задано `ADMIN_PASSWORD` (див. [Багатокористувацький режим і автентифікація](/uk/docs/multi-user/authentication)),
кожна приманка, місце й улов мають кнопку **Створити посилання**; без входу її немає.
:::

## Створити посилання

1. Відкрийте приманку, місце чи улов.
2. Натисніть **Створити посилання**, потім **Копіювати** і надішліть посилання.
3. Щоб прибрати сторінку, натисніть **Видалити посилання**.

Посилання відкриває сторінку **лише для читання** з цим одним записом; решта даних лишається
приватною. Воно будується з вашого `BASE_URL`, тож адреса з домашньої мережі відкривається лише в ній.

## Пов'язане

- Посилання для поширення працюють для [приманок](/uk/docs/features/lures), [місць](/uk/docs/features/spots) і [уловів](/uk/docs/features/catches).
