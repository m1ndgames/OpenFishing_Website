## Додайте першу приманку

1. Виберіть **Додати**, а потім **Приманку**.
2. Додайте фото. Це єдине обов'язкове поле.
3. Додайте те, що знаєте: бренд, назву, тип, колір, розмір, вагу, кількість, теги, види риби, на
   які вона, **Глибина ходу**, **Тип водойми** і **Умови освітлення**.
4. Виберіть **Зберегти приманку**.

Вона отримує наступний номер (наприклад, `#0001`), готовий для [QR-мітки](/uk/docs/features/qr-labels). Пропуски після видалених приманок не заповнюються, але якщо видалити найновішу приманку, її номер отримає наступна. Якщо [функції ШІ](/uk/docs/ai/ai-features) налаштовано, **Визначити за фото** у цій
формі може заповнити дані з фото.

## Що можна відстежувати

- **Фото**: одне фото на приманку, зберігається на томі з завантаженнями.
- **Теги та види**: категоризуйте приманки й зазначайте цільові види.
- **Обране**: позначайте приманки, до яких звертаєтеся найчастіше.
- **Загублені приманки**: позначте приманку як загублену. Вона лишається в колекції з позначкою
  **Загублена** і зберігає історію.
- **Кількість**: скільки одиниць певної приманки у вас є.
- **Послідовні номери**: кожна приманка отримує автоматичний послідовний ID (напр. `#0001`), зручний
  для [QR-міток](/uk/docs/features/qr-labels).

## Пошук приманок

- **Пошук**: шукає в назві, бренді, типі, кольорі й тегах; список оновлюється під час введення.
- **Фільтри**: звузьте список за **Тип**, **Глибина ходу**, **Умови освітлення**, **Вид риби**, **Вибрані**, **З уловом**, **Розмір** або **Вага**. Виберіть значення вдруге, щоб натомість його виключити.
- **Підказки**: назва, бренд, тип, колір і види пропонують значення під час введення.

## Пов'язане

- Друкуйте [QR-мітки](/uk/docs/features/qr-labels) для непозначених приманок.
- Опублікуйте приманку публічно за допомогою [посилання для поширення](/uk/docs/features/share-links).
- Прив'яжіть приманку до [улову](/uk/docs/features/catches).
