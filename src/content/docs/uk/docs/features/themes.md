OpenFishing має чотири кольорові теми, кожну в темному й світлому варіанті. Обидва параметри
задаються в **Налаштування → Вигляд**, де також вибирається [мова](/uk/docs/features/languages) застосунку.

## Теми

- **Ocean**: глибокий темно-синій із блакитним акцентом. Стандартна тема й вигляд цього сайту.
- **Forest**: зелений акцент.
- **Sunset**: помаранчевий акцент.
- **Dusk**: фіолетовий акцент.

## Темний, світлий або системний

Виберіть **Темний**, **Світлий** або **Система**, щоб слідувати налаштуванню телефона чи комп'ютера.

## Кого це стосується

З увімкненим [входом](/uk/docs/multi-user/authentication) кожен обирає власну тему й вигляд. Без входу вибір діє для
всіх, хто користується екземпляром.

Адмін задає **Вигляд за замовчуванням** у **Налаштування → Адмін**: колірний режим і тему для екрана входу та для тих, хто ще не
вибрав власні.
