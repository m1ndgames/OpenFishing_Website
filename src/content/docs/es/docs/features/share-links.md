Los **enlaces para compartir** te permiten publicar un solo **señuelo**, **punto** o **captura** como una página
pública de solo lectura: práctico para presumir una captura o compartir un señuelo con un amigo sin darle
acceso a toda tu instancia.

:::note
Los enlaces para compartir necesitan inicio de sesión. Con `ADMIN_PASSWORD` definido (consulta
[Multiusuario y autenticación](/es/docs/multi-user/authentication)), cada señuelo, punto y captura muestra **Crear enlace para compartir**; sin inicio de sesión no aparece.
:::

## Crear un enlace para compartir

1. Abre el señuelo, el punto o la captura.
2. Selecciona **Crear enlace para compartir**, luego **Copiar**, y envía el enlace.
3. Para retirar la página, selecciona **Eliminar enlace**.

El enlace abre una página de **solo lectura** con ese elemento; el resto de tus datos sigue siendo
privado. Se crea con tu `BASE_URL`, así que una dirección de tu red doméstica solo funciona en ella.

## Relacionado

- Los enlaces para compartir sirven para [señuelos](/es/docs/features/lures), [puntos](/es/docs/features/spots) y [capturas](/es/docs/features/catches).
