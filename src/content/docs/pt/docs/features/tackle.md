## Adicionar o teu equipamento

1. Abre **Equipamento** no menu.
2. Escolhe um separador: **Canas**, **Carretilhas**, **Linhas** ou **Combos**.
3. Seleciona o botão de adicionar, por exemplo **Adicionar cana**.
4. Preenche pelo menos o **Modelo** (numa linha, **Modelo / Nome**) e guarda, por exemplo com **Guardar cana**.

## Combos

Um combo é o conjunto com que pescas de facto: dá-lhe um **Nome do combo**, escolhe uma **Cana** e uma **Carretilha** e seleciona **Guardar combo**. Se quiseres, acrescenta ao combo o **Terminal Tackle** (estralho, anzol, chumbo).

## Trocas de linha

Numa carretilha, **Montar linha** regista que linha lhe puseste e quando, para veres o histórico.
