## Adiciona a tua primeira isca

1. Escolhe **Adicionar** e depois **Isca**.
2. Adiciona uma foto. É o único campo obrigatório.
3. Junta o que souberes: marca, nome, tipo, cor, tamanho, peso, quantas tens, etiquetas, as espécies
   a que se destina, **Profundidade de nado**, **Tipo de água** e **Condições de luz**.
4. Escolhe **Guardar isca**.

Recebe o número seguinte (como `#0001`), pronta para uma [etiqueta QR](/pt/docs/features/qr-labels). Os números de iscas apagadas não são preenchidos, mas se apagares a tua isca mais recente, o número dela passa para a seguinte. Com as [funcionalidades de IA](/pt/docs/ai/ai-features) configuradas, **Identificar pela
foto** neste formulário pode preencher os dados a partir da foto.

## O que podes registar

- **Foto**: uma foto por isca, guardada no teu volume de uploads.
- **Etiquetas e espécies**: categoriza as iscas e anota as espécies-alvo.
- **Favoritos**: marca as iscas a que recorres mais.
- **Iscas perdidas**: marca uma isca como perdida. Fica na tua coleção com a etiqueta **Perdida** e
  mantém o histórico.
- **Quantidade**: quantas tens de uma determinada isca.
- **Números sequenciais**: cada isca recebe um ID sequencial automático (p. ex. `#0001`), útil
  para [etiquetas QR](/pt/docs/features/qr-labels).

## Encontrar iscas

- **Pesquisar**: procura no nome, marca, tipo, cor e tags; a lista atualiza-se enquanto escreves.
- **Filtros**: restringe a lista por **Tipo**, **Profundidade de nado**, **Condições de luz**, **Espécie de peixe**, **Favoritos**, **Com captura**, **Tamanho** ou **Peso**. Seleciona um valor uma segunda vez para o excluir.
- **Sugestões**: nome, marca, tipo, cor e espécies sugerem valores enquanto escreves.
