## Adicionar um local

1. Seleciona **Adicionar** e escolhe **Local**.
2. Escreve um **Nome** e define a **Localização**: toca no mapa, seleciona **Usar a minha localização** ou
   **Usar localização da foto** se uma foto que adicionaste tiver dados GPS. A localização é obrigatória.
3. Acrescenta fotos e notas se quiseres e seleciona **Guardar local**.

## O que podes registar

- **Localização**: o marcador, colocado com um toque no mapa, com a tua posição atual ou com os dados GPS de uma foto.
- **Fotos**: anexa imagens do local.
- **Notas**: descreve o acesso, a estrutura ou as condições.
- **Tags**: etiquetas curtas para voltares a encontrar os teus locais.

## Proximidade das capturas

Qualquer [captura](/pt/docs/features/catches) registada **a menos de 100 m** de um local aparece automaticamente no mais próximo. Com o
tempo vês que locais dão mesmo peixe, sem ligar cada captura à mão.
