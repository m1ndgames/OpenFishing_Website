title: Ligações de partilha

---

As **ligações de partilha** permitem-te publicar uma única **isca**, **local** ou **captura** como uma página
pública só de leitura: útil para mostrar uma captura ou partilhar uma isca com um amigo sem lhe dar acesso a
toda a tua instância.

:::note
As ligações de partilha precisam de início de sessão. Com `ADMIN_PASSWORD` definido (vê
[Multiutilizador e autenticação](/pt/docs/multi-user/authentication)), cada isca, local e captura mostra **Criar link de partilha**; sem início de sessão o botão não aparece.
:::

## Criar um link de partilha

1. Abre a isca, o local ou a captura.
2. Seleciona **Criar link de partilha**, depois **Copiar**, e envia o link.
3. Para retirar a página, seleciona **Remover link**.

O link abre uma página **só de leitura** apenas com esse item; o resto dos teus dados continua privado.
É feito a partir do teu `BASE_URL`, por isso um endereço da rede de casa só abre nessa rede.
