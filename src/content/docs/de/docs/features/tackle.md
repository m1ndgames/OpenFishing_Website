## Ausrüstung eintragen

1. Öffne **Ausrüstung** im Menü.
2. Wähle einen Tab: **Ruten**, **Rollen**, **Schnüre** oder **Combos**.
3. Tippe auf die Schaltfläche zum Hinzufügen, zum Beispiel **Rute hinzufügen**.
4. Fülle mindestens das **Modell** aus (bei einer Schnur **Modell / Name**) und speichere, zum Beispiel mit **Rute speichern**.

## Combos

Ein Combo ist das Setup, mit dem du wirklich angelst: Gib einen **Combo-Name** ein, wähle eine **Rute** und eine **Rolle** und tippe auf **Combo speichern**. Auf Wunsch ergänzt du am Combo **Terminal Tackle** (Vorfach, Haken, Blei).

## Schnurwechsel

Bei einer Rolle hält **Schnur aufspulen** fest, welche Schnur du wann aufgespult hast. So siehst du ihren Verlauf.

## Verwandt

- Wähle das Combo unter **Weitere Angaben**, wenn du einen [Fang](/de/docs/features/catches) einträgst.
- Deine Ausrüstung ist Teil jeder [Sicherung](/de/docs/backup/backup-restore).
