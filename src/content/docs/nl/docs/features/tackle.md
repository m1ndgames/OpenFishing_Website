## Je uitrusting toevoegen

1. Open **Uitrusting** in het menu.
2. Kies een tabblad: **Hengels**, **Molens**, **Lijnen** of **Combo's**.
3. Kies de knop om toe te voegen, bijvoorbeeld **Hengel toevoegen**.
4. Vul minstens het **Model** in (bij een lijn **Model / Naam**) en sla op, bijvoorbeeld met **Hengel opslaan**.

## Combo's

Een combo is de set waarmee je echt vist: geef hem een **Combo-naam**, kies een **Hengel** en een **Molen** en kies **Combo opslaan**. Voeg desgewenst **Terminal Tackle** (onderlijn, haak, lood) aan de combo toe.

## Lijnwissels

Bij een molen legt **Lijn opspulen** vast welke lijn je erop zette en wanneer, zodat je de geschiedenis ziet.

## Gerelateerd

- Kies de combo onder **Meer details** als je een [vangst](/nl/docs/features/catches) vastlegt.
- Je uitrusting zit in elke [back-up](/nl/docs/backup/backup-restore).
