OpenFishing is beschikbaar in **9 talen**. Kies de jouwe onder **Instellingen → Uiterlijk**, op dezelfde pagina als het
[thema](/nl/docs/features/themes).

- English
- Deutsch
- Français
- Español
- Italiano
- Nederlands
- Polski
- Português
- Українська

Van taal wisselen werkt ook in [demomodus](/nl/docs/demo/demo-mode).
