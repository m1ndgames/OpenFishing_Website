## Add your gear

1. Open **Tackle** from the menu.
2. Choose a tab: **Rods**, **Reels**, **Lines** or **Combos**.
3. Select the add button, for example **Add Rod**.
4. Fill in at least the **Model** (for a line, **Model / Name**), then save, for example with **Save Rod**.

## Combos

A combo is the setup you actually fish: give it a **Combo Name**, pick a **Rod** and a **Reel**, then select **Save Combo**. Add **Terminal Tackle** (leader, hook, weight) to a combo if you like.

## Line changes

On a reel, **Spool Line** records which line you put on it and when, so you can see its history.
