## Log a catch

1. Select **Add** and choose **Catch**.
2. Enter the **Species**.
3. Set the **Location**: tap the map, select **Use my location** or **Use photo location**, or pick one under
   **Use a saved spot**. The location is required.
4. Add whatever else you like: photos, the **Lure**, length and weight. Under **More details** you'll find
   the **Combo**, **Retrieve Style**, **Notes** and **Catch & Release**.
5. Select **Log Catch**.

Your server saves the [Bite Index](/docs/features/bite-index) with it, using the weather at that place right now. Log
catches at the water for an accurate score.

## Fields

- **Species**: what you caught.
- **Lure**: the [lure](/docs/features/lures) from your library that caught it.
- **Length**, **Weight**: measurements for the record.
- **Location**: where you caught it. The nearest saved [spot](/docs/features/spots) within 100 m shows the catch automatically.
- **Combo**: the rod, reel and line you fished with, set up under [Tackle](/docs/features/tackle).
- **Retrieve Style**: how you were fishing it.
- **Catch & Release**: whether the fish was released.

## Export to a spreadsheet

Under **Settings → Export**, pick a **From** and **To** date and select **Download CSV**. The file opens in any
spreadsheet app. It is not a backup; for that, see [Backup & restore](/docs/backup/backup-restore).
