OpenFishing is available in **9 languages**. Pick yours under **Settings → Appearance**, the same page where you
choose a [theme](/docs/features/themes).

- English
- Deutsch
- Français
- Español
- Italiano
- Nederlands
- Polski
- Português
- Українська

Switching language still works in [demo mode](/docs/demo/demo-mode).
