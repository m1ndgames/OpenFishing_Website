## Add a spot

1. Select **Add** and choose **Spot**.
2. Enter a **Name** and set the **Location**: tap the map, select **Use my location**, or **Use photo location** if a photo
   you added has GPS data. The location is required.
3. Add photos and notes if you like, then select **Save Spot**.

## What you can track

- **Location**: the pin, placed with a tap on the map, your current position or a photo's GPS data.
- **Photos**: attach images of the spot.
- **Notes**: describe access, structure, or conditions.
- **Tags**: short labels that help you find spots again.

## Catch proximity

Each [catch](/docs/features/catches) logged **within 100 m** of a spot shows up on the nearest one automatically. Over time you
see which places actually produce fish, without linking each catch by hand.
