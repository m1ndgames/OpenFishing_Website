## Add your first lure

1. Select **Add** and choose **Lure**.
2. Add a photo. It's the only thing you have to fill in.
3. Add what you know: brand, name, type, colour, size, weight, how many you have, tags, the
   species it's for, **Running Depth**, **Water Type** and **Light Conditions**.
4. Select **Save Lure**.

It gets the next number (such as `#0001`), ready for a [QR label](/docs/features/qr-labels). Gaps left by deleted lures aren't filled, but deleting your newest lure frees its number for the next one. With [AI features](/docs/ai/ai-features) set up, **Identify from photo** on this form can fill in
details from the photo.

## What you can track

- **Photo**: one photo per lure, stored on your uploads volume.
- **Tags & species**: categorize lures and note the species they target.
- **Favourites**: flag the lures you reach for most.
- **Lost-lure tracking**: mark a lure as lost. It stays in your collection with a **Lost**
  badge and keeps its history.
- **Amount**: how many of a given lure you have.
- **Sequential numbers**: each lure gets an automatic sequential ID (e.g. `#0001`), handy
  for [QR labels](/docs/features/qr-labels).

## Finding lures

- **Search**: matches name, brand, type, colour and tags; the list updates as you type.
- **Filters**: narrow the list by **Type**, **Running Depth**, **Light Conditions**, **Fish Species**, **Favourites**, **Has Catch**, **Size** or **Weight**. Select a value a second time to exclude it instead.
- **Suggestions**: name, brand, type, colour and species suggest values as you type.
