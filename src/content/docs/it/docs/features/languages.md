OpenFishing è disponibile in **9 lingue**. Scegli la tua in **Impostazioni → Aspetto**, la stessa pagina in cui scegli
un [tema](/it/docs/features/themes).

- English
- Deutsch
- Français
- Español
- Italiano
- Nederlands
- Polski
- Português
- Українська

Il cambio di lingua funziona anche in [modalità demo](/it/docs/demo/demo-mode).
