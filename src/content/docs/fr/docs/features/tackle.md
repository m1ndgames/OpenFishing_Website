## Ajouter votre matériel

1. Ouvrez **Matériel** dans le menu.
2. Choisissez un onglet : **Cannes**, **Moulinets**, **Fils** ou **Combos**.
3. Sélectionnez le bouton d'ajout, par exemple **Ajouter une canne**.
4. Renseignez au moins le **Modèle** (pour un fil, **Modèle / Nom**), puis enregistrez, par exemple avec **Enregistrer la canne**.

## Combos

Un combo est le montage que vous pêchez vraiment : donnez-lui un **Nom du combo**, choisissez une **Canne** et un **Moulinet**, puis sélectionnez **Enregistrer le combo**. Ajoutez si vous voulez un **Bas de ligne** (avançon, hameçon, plomb) au combo.

## Changements de fil

Sur un moulinet, **Monter un fil** enregistre quel fil vous y avez mis et quand, pour en voir l'historique.

## Associé

- Choisissez le combo sous **Plus de détails** quand vous enregistrez une [prise](/fr/docs/features/catches).
- Votre matériel fait partie de chaque [sauvegarde](/fr/docs/backup/backup-restore).
