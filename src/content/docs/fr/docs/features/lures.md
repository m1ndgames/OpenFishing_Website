## Ajouter votre premier leurre

1. Choisissez **Ajouter**, puis **Leurre**.
2. Ajoutez une photo. C'est le seul champ obligatoire.
3. Ajoutez ce que vous savez : marque, nom, type, couleur, taille, poids, quantité, tags, espèces
   visées, **Profondeur de nage**, **Type d'eau** et **Conditions lumineuses**.
4. Choisissez **Enregistrer le leurre**.

Il reçoit le numéro suivant (par exemple `#0001`), prêt pour une [étiquette QR](/fr/docs/features/qr-labels). Les trous laissés par les leurres supprimés ne sont pas comblés, mais supprimer votre leurre le plus récent libère son numéro pour le suivant. Avec les [fonctions d'IA](/fr/docs/ai/ai-features) configurées,
**Identifier depuis la photo** dans ce formulaire peut remplir les détails à partir de la photo.

## Ce que vous pouvez suivre

- **Photo** : une photo par leurre, stockée sur votre volume d'uploads.
- **Tags & espèces** : catégorisez les leurres et notez les espèces ciblées.
- **Favoris** : marquez les leurres que vous utilisez le plus.
- **Suivi des leurres perdus** : marquez un leurre comme perdu. Il reste dans votre collection
  avec un badge **Perdu** et garde son historique.
- **Quantité** : combien d'un leurre donné vous possédez.
- **Numéros séquentiels** : chaque leurre reçoit un identifiant séquentiel automatique (p. ex. `#0001`), pratique
  pour les [étiquettes QR](/fr/docs/features/qr-labels).

## Trouver des leurres

- **Rechercher** : cherche dans le nom, la marque, le type, la couleur et les tags ; la liste se met à jour pendant la saisie.
- **Filtres** : affinez la liste par **Type**, **Profondeur de nage**, **Conditions lumineuses**, **Espèce de poisson**, **Favoris**, **Avec prise**, **Taille** ou **Poids**. Sélectionnez une valeur une deuxième fois pour l'exclure.
- **Suggestions** : le nom, la marque, le type, la couleur et les espèces proposent des valeurs pendant la saisie.

## Associé

- Imprimez des [étiquettes QR](/fr/docs/features/qr-labels) pour les leurres non étiquetés.
- Publiez un leurre publiquement avec un [lien de partage](/fr/docs/features/share-links).
- Reliez un leurre à une [prise](/fr/docs/features/catches).
