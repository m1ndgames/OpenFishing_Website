## Enregistrer une prise

1. Choisissez **Ajouter**, puis **Prise**.
2. Saisissez l'**Espèce**.
3. Indiquez la **Localisation** : touchez la carte, sélectionnez **Utiliser ma position** ou **Utiliser la position de la photo**, ou choisissez-en
   une sous **Utiliser un spot enregistré**. La localisation est obligatoire.
4. Ajoutez ce que vous voulez : photos, le **Leurre**, longueur et poids. Sous **Plus de détails** se trouvent
   **Combo**, **Style de récupération**, **Notes** et **Attraper & Relâcher**.
5. Choisissez **Enregistrer la prise**.

Votre serveur enregistre l'[indice de morsure](/fr/docs/features/bite-index) avec elle, à partir de la météo de ce lieu à cet
instant. Enregistrez vos prises au bord de l'eau pour une note juste.

## Champs

- **Espèce** : ce que vous avez pris.
- **Leurre** : le [leurre](/fr/docs/features/lures) de votre collection qui l'a pris.
- **Longueur**, **Poids** : les mesures pour le record.
- **Localisation** : où vous l'avez pris. Le [spot](/fr/docs/features/spots) enregistré le plus proche, à moins de 100 m, affiche la prise automatiquement.
- **Combo** : la canne, le moulinet et la ligne utilisés, configurés dans [Matériel](/fr/docs/features/tackle).
- **Style de récupération** : comment vous le pêchiez.
- **Attraper & Relâcher** : si le poisson a été relâché.

## Exporter vers un tableur

Dans **Paramètres → Export**, choisissez les dates **Du** et **Au** puis sélectionnez **Télécharger CSV**. Le fichier
s'ouvre dans n'importe quel tableur. Ce n'est pas une sauvegarde ; pour cela, voir
[Sauvegarde et restauration](/fr/docs/backup/backup-restore).
